## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In an agentic planner, a security flaw can lead to "jailbreaking" the robot's mission. If you discover a vulnerability affecting the **prompt integrity**, **sub-task injection**, or **state-query poisoning**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows forcing the robot into dangerous states, bypassing task priorities, or executing unauthorized command sequences.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
